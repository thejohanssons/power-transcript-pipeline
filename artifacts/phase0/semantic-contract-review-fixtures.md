## How to review

Two reviewers must independently complete every blank in the table before discussing results. For each excerpt, record one `ContextType`, one `Category`, a proposed `Topic ID` or `unclassified`, and whether a topic case should be linked, proposed, or not created. Identify the exact source locator and write a short rationale.

This pack intentionally contains competing interpretations: concerns versus risks, proposals versus decisions, actions versus progress, and strategy versus operating status. It is a calibration exercise, not a production extraction set. The source includes personnel-sensitive content; retain it inside the approved repository/security boundary and do not publish the excerpts externally.

### Agreement rule

For a fixture to agree, both reviewers must choose the same ContextType, Category, Topic ID (or `unclassified`), and case treatment, or document a jointly approved adjudication. Phase 0 exit requires agreement on 10–20 representative excerpts; this pack contains 12 and must be supplemented with other sources before final approval if its single-transcript sampling is judged insufficient.

## Facilitator adjudication checklist

For each disagreement, answer in order:

1. Does the excerpt state a communicative posture (`ContextType`) separately from its business nature (`Category`)?
2. Does the source assert a potential adverse future event (`Risk`) or an already-realised adverse state (`Issue`)?
3. Has a decision been authorised, or is it only a proposal, recommendation, or future decision point?
4. Is work actually assigned/committed (`Action`) or is status being described (`Progress`)?
5. Which canonical topic best describes the evidence? If none is defensible, mark `unclassified` rather than using `T15` as a fallback.
6. Does the excerpt identify a distinct live matter that justifies a topic case? If uncertain, record a reviewable candidate rather than merging silently.
7. Record the adjudication decision, rationale, facilitator, date, and contract version in a separate append-only review event when the data model is implemented.
