5. FAILURE ANALYSIS (COMBINED)

  All failures across both phases trace to two root causes:

  Root cause 1 (Domain + Outcome + Aspect — 3 records):
  Azure pipeline topic "Strategic Direction & Alignment" with domain=Strategy,
  category=Strategy. See Phase 1 failure analysis below for full detail.

  Root cause 2 (Outcome only — 7 records):
  Empty topic records where the pipeline could not classify content and used
  'Governance' or 'Process' as fallback category values. No Key Facts populated.
  These are pipeline data quality failures, not taxonomy gaps.

  ────────────────────────────────────────
  Phase 1 failure detail — Strategic Direction & Alignment:

  All failures (3 Domain, 2 Outcome, 3 Aspect) trace to a single root cause:

  Root cause: Azure pipeline topic "Strategic Direction & Alignment" with
              domain=Strategy, category=Strategy

  This is a legacy taxonomy artefact from the Azure pipeline, not evidence of
  a missing v0.2 concept. The v0.2 framework deliberately decomposed the
  "Strategy" concept into:

    ExecutiveScope = Strategic     (level of organisational attention)
    Disposition = Decision         (what commitment was made)
    Domain = accountable function  (who owns it)

  The failure therefore validates the v0.2 design rationale rather than
  challenging it. "Strategy" as a domain, category, and topic name is the
  exact ambiguity the framework was designed to eliminate.

  Provisional classification for "Strategic Direction & Alignment":
    Domain:         Product Management or Commercial (context-dependent)
    Entity Type:    Initiative
    Aspect:         Performance
    Outcome:        Progress or Insight
    Disposition:    Decision
    ExecutiveScope: Strategic

  This classification requires no new taxonomy values.
