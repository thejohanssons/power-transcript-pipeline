- Monorepo: packages/pipeline (Azure), packages/api-worker (CF Worker), packages/d1 (schema), packages/sync-worker (future)
- Config path resolution: $PSScriptRoot/../../config (local dev) → ./config (Azure deploy)
- classification_rules.json: gitignored secret, in repo root (not packages/pipeline/)
- pipeline_config.json: gitignored secret, in packages/pipeline/
- All PS1 scripts use $PSScriptRoot for self-relative paths
